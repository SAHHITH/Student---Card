# 🎓 Student Card Management System

### A Beginner-Friendly React JS Mini Project

A modern and responsive **Student Card Management System** built using React JS. This project demonstrates reusable components, Props, State management and dynamic rendering by displaying student information through interactive profile cards.

---

## 📌 Project Overview

The Student Card Management System is a web application designed to display and manage student information through reusable React components.

Instead of manually creating individual student cards, the application uses a single reusable `StudentCard` component to display multiple student profiles dynamically.

The dashboard provides student statistics, search functionality, department filtering and student management features.

## ✨ Features

- 📊 Student Dashboard
- 👨‍🎓 Reusable Student Profile Cards
- 🔍 Search Students by Name or Register Number
- 🏢 Filter Students by Department
- 👤 View Complete Student Details
- ➕ Add New Students
- ✏️ Edit Student Information
- 🗑️ Delete Student Records
- 📱 Responsive User Interface
- 💾 Local Storage Support (Optional)

## ⚙️ Installation and Setup

### Prerequisites

- Node.js
- npm
- VS Code or Antigravity IDE

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Navigate to the Project

```bash
cd student-card-system
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Install Lucide React

```bash
npm install lucide-react
```

### Step 5: Run the Application

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.
